# JobSignal V1 PRD

## V1 thesis

JobSignal is a personal job-search command center. When the user marks a job as applied, JobSignal captures the job posting, saves the job description, creates or updates an application record, analyzes the opportunity, and tracks the recruiting pipeline from that point forward.

## Main V1 decision

**Mark Applied = capture job + create application + store JD + queue AI analysis + add timeline event.**

There is no separate “capture random job” workflow required in V1.

## Core modules

1. Chrome extension Mark Applied flow.
2. Application pipeline.
3. Job description intelligence.
4. Gmail recruiting signal scanner.
5. Manual review queue.
6. Confirm rejection + Gmail archive.
7. Dashboard analytics.
